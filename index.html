Fitur

Semua yang kamu cek tiap hari, tanpa pindah jendela.

Notch tertutup menampilkan hal terpenting. Saat dibuka, kamu dapat tab untuk beranda, OHARA, kontrol sistem, rekam layar, dan lainnya.

Pemutar musik

Lagu yang sedang diputar dari aplikasi apa pun, lengkap dengan kontrol. Opsi supaya notch tetap terbuka selama musik main.

Kalender

Hubungkan tautan kalender (.ics) dan lihat acara berikutnya langsung di notch yang tertutup.

Notifikasi dari semua aplikasi

Banner bergaya macOS di kanan atas, ditumpuk per aplikasi. Ekstensi Chrome opsional membawa notifikasi WhatsApp Web dan situs lain.

Control Center

Wi-Fi, Bluetooth, mode gelap, Focus, bahasa keyboard, baterai, kecerlangan, volume, ikon tray yang tersembunyi, dan lokasi.

Absensi OHARA

Check in, pause, dan check out, target harian, rencana kerja, serta tugas yang sedang dikerjakan. Statusnya terlihat juga saat notch tertutup.

Update otomatis

Versi baru diunduh di latar belakang dan dipasang senyap di Windows, lalu notch terbuka lagi sendiri. Bisa dimatikan di Settings.

Catatan pemasangan Windows
  • Installer belum ditandatangani, jadi SmartScreen bisa memperingatkan. Pilih More info, lalu Run anyway.
  • Arahkan kursor ke tengah atas layar untuk membuka notch. Pengaturan ada di tab Settings.
  • Ekstensi Chrome untuk notifikasi situs web ada di folder instalasi, di dalam resources\app\chrome-extension. Muat lewat chrome://extensions → Load unpacked.
